# Probability

## 📖 Overview

This chapter introduces classical probability, which measures the chance of an event happening.

## 🧠 Key Concepts

- **Experiment:** An action with possible outcomes, such as tossing a coin.
- **Outcome:** A possible result of an experiment.
- **Event:** A set of favourable outcomes.
- **Equally likely outcomes:** Outcomes that have the same chance of occurring.
- **Impossible event:** An event with probability 0.
- **Sure event:** An event with probability 1.
- **Complementary event:** The event "not E" if the event is `E`.

## 📐 Formulas

Classical probability:

$$P(E)=\frac{\text{Number of favourable outcomes}}{\text{Total number of equally likely outcomes}}$$

Range of probability:

$$0\le P(E)\le 1$$

Complement:

$$P(\text{not }E)=1-P(E)$$

For an impossible event:

$$P(E)=0$$

For a sure event:

$$P(E)=1$$

## ✏️ Examples

**Example 1:** A coin is tossed once. Probability of getting a head:

$$P(H)=\frac{1}{2}$$

**Example 2:** A die is thrown once. Probability of getting an even number:

Favourable outcomes: 2, 4, 6.

$$P(E)=\frac{3}{6}=\frac{1}{2}$$

## 💡 Important Points

- Probability is always between 0 and 1.
- Total outcomes must be equally likely.
- Probability can be written as a fraction, decimal, or percentage.
- Complement probability is often faster.

## ⚠️ Common Mistakes

- Counting favourable outcomes incorrectly.
- Using probability greater than 1.
- Forgetting to simplify fractions.
- Applying the classical formula when outcomes are not equally likely.

## 📝 Exam Tips

- List the sample space for simple questions.
- Check if the event asks for "at least", "not", or "exactly".
- Use complement for "not" questions.

## ⚡ Quick Revision

- Probability = favourable outcomes / total outcomes.
- Minimum probability is 0.
- Maximum probability is 1.
- $$P(\text{not }E)=1-P(E)$$.
