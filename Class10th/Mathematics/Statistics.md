# Statistics

## 📖 Overview

This chapter studies how to find mean, median, and mode for grouped data.

## 🧠 Key Concepts

- **Grouped data:** Data arranged in class intervals.
- **Class mark:** Midpoint of a class interval.
- **Frequency:** Number of observations in a class.
- **Mean:** Average value of the data.
- **Median:** Middle value of the data.
- **Mode:** Most frequent value of the data.
- **Methods for mean in syllabus:**
  - Direct method
  - Assumed mean method
  - Step deviation method
- **Bimodal cases:** Avoided in the syllabus.

## 📐 Formulas

Class mark:

$$x_i=\frac{\text{upper limit}+\text{lower limit}}{2}$$

Mean, direct method:

$$\bar{x}=\frac{\sum f_ix_i}{\sum f_i}$$

Mean, assumed mean method:

$$\bar{x}=a+\frac{\sum f_id_i}{\sum f_i}$$

where:

$$d_i=x_i-a$$

Mean, step deviation method:

$$\bar{x}=a+h\frac{\sum f_iu_i}{\sum f_i}$$

where:

$$u_i=\frac{x_i-a}{h}$$

Median:

$$\text{Median}=l+\left(\frac{\frac{N}{2}-cf}{f}\right)h$$

Mode:

$$\text{Mode}=l+\left(\frac{f_1-f_0}{2f_1-f_0-f_2}\right)h$$

## ✏️ Examples

**Example 1:** If class interval is 20-30, class mark is:

$$x_i=\frac{20+30}{2}=25$$

**Example 2:** If $$\sum f_ix_i=500$$ and $$\sum f_i=25$$, then:

$$\bar{x}=\frac{500}{25}=20$$

## 💡 Important Points

- Median class is the class where cumulative frequency first becomes greater than $$\frac{N}{2}$$.
- Modal class has the highest frequency.
- Step deviation is useful when class width is common.
- Use class marks for mean.

## ⚠️ Common Mistakes

- Choosing the wrong median class.
- Using class intervals directly instead of class marks for mean.
- Confusing cumulative frequency with frequency.
- Forgetting that $$N=\sum f_i$$.

## 📝 Exam Tips

- Make a neat table with all required columns.
- For median, calculate cumulative frequency carefully.
- For mode, identify $$f_0,f_1,f_2$$ from classes around the modal class.

## ⚡ Quick Revision

- Mean uses all observations.
- Median uses cumulative frequency.
- Mode uses the modal class.
- Class mark is the midpoint of a class interval.
